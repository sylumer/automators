# Overview
Mac Automation is a plugin for the [[Stream Deck]] focused on support for triggering automations on the Mac. It includes actions for opening apps/files, running scripts (shell scripts, [[AppleScript]], [[JXA]]), opening URLs (including dealing with self-signed certificate URLs), running Apple [[Shortcuts]], and triggering [[Keyboard Maestro]] macros.

# Notes
- Created by [[Stephen Millard]], this plugin is free to download and use.
- The plugin offers multiple options for specifying the launching of [[Shortcuts]] shortcuts and [[Keyboard Maestro]] macros.
