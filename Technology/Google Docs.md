# Overview  
Google Docs is a cloud-based word processor application that allows users to create, edit, and share documents online. Designed for both personal and collaborative use, it offers tools for data content creation and styling.

# Operating Systems
- Online, and some offline features.
- iOS
- iPadOS
- Android

# Features  
- Typical word processor functionality.
- Collaborative working means that multiple users can work on the same documents simultaneously with changes reflected instantaneously.
- Seamless integration with [[Google Drive]], [[Google Sheets]], [[Google Slides]], and other [[Google]] services.

# Notes  
- This is an online solution with some progressive web app-like features, though it is not a progressive web app.
- Supports [[Google App Script]] for automation.
