# Overview
Dropbox Paper is a web-based, collaborative workspace and document-editing service that allows groups or users to create, manage, and coordinate content online. It functions much like a digital whiteboard, where users can combine traditional text with images, multimedia (embeds), code snippets, and task lists within a single shared document. Editing is in near real-time and includes more project management style features alongside the document editing features.

# Features

- **Near Real-time Collaboration**: Multiple users can edit, format, and comment on documents simultaneously, seeing changes instantly.
- **Task Management**: Create to-do lists, assign tasks to team members using *@mentions*, and set due dates, with automatic reminders to keep projects on track.
- **Multimedia Embedding**: Seamlessly embed rich media from various sources (e.g. YouTube).
- **Document Management**: All Paper documents are organised and stored within your main [[Dropbox]] file system, leveraging its security and file management.
- **Calendar Integration**: Connect a calendar to automatically create meeting notes templates pre-filled with the agenda, date, and attendees.
- **Version History**.
- **Presentation Mode**.
- **Templates**: Access a variety of pre-built templates for common tasks like project plans, meeting notes, and creative briefs.
