# Overview
A content management system (CMS) is a software application used to create, manage, and modify digital content, typically on a web-hosted site. It does so without the need for specialised technical knowledge or direct interaction with programming code, providing a user-facing user interface. It serves as a centralised platform that separates the content creation layer (text, images, and other media) from the presentation layer (e.g. a website's design and code), making it highly accessible for non-technical users. 

Essentially, a CMS provides a user-friendly graphical interface with tools for authoring, collaboration, editing, versioning, publishing, and maintaining the flow of information.
