# Overview
Scanner Pro by [[Readdle]] is a mobile app that utilises a device camera to take a picture and converts it into a scanned document format. The app includes scanning assistance functionality such as deskewing, edge tracking & auto-crop, auto scan, image filters and multiple export options.

# Operating Systems
- iOS
- iPadOS

# Features
- Deskew and perspective adjustment.
- Edge tracking and automatic cropping.
- Multi-page scans.
- Filters to improve clarity of scan.
- Password protect documents.
- Multiple export file formats and customisable workflows for naming, export location, etc.
- Optical Character Recognition ([[OCR]]).
- Automatic upload (optional).

# Notes
- Automation is available for Scanner Pro via [[Shortcuts]].
