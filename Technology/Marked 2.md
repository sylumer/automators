# Overview
Marked 2, developed by [[Brett Terpstra]], is a Mac utility designed as a live previewer and an advanced writing analysis tool for plain text and Markdown files. It functions as a companion app to any text editor, providing a near instant, customisable visual rendering of how the raw [[Markdown]] will look when published as [[HTML]], PDF, or other formats. Beyond simple rendering, Marked 2 offers powerful features for improving prose, such as detailed document statistics and the ability to highlight overused words or repetitions,  making it an indispensable part of a conscientious writer's workflow.

# Features

- **Live, Customisable Previews**: Provides an instant [[HTML]] preview that updates every time you save your document in your favorite text editor, with various built-in themes and support for custom [[CSS]].
- **Advanced Document Statistics**: Offers detailed metrics including word count, character count, reading time, and readability scores (e.g., Flesch-Kincaid).
- **Writing Analysis Tools**: Highlights overused words, repeated phrases, and passive voice to help you edit and improve your writing.
- **Multi-File Document Support**: Can compile and preview documents made up of multiple text files using special include syntax or index formats from apps like [[Scrivener]] and [[Leanpub]].
- **Flexible Export Options**: Export your final work into a variety of formats including PDF, DOCX (Word), Rich Text Format (RTF), Open Document Text (ODT), and self-contained [[HTML]].
- **Navigation and Organisation**: Automatically generates a table of contents for easy navigation of long documents, with a "*fast switcher*" search feature and a *Mini Map* overview.
- **Wide Markup Support**: Supports various markup languages and processors beyond standard [[Markdown]], including MultiMarkdown, GitHub Flavored Markdown, Fountain (for screenwriters), and CriticMarkup (for peer review).
- **Automation and Workflow Integration**: Features link validation, autoscroll functionality (can be used as a teleprompter), [[AppleScript]] dictionary, and a [[URL Schemes\|URL scheme]] for integration into custom workflows.
- **Folder Watching**: Can monitor an entire folder and automatically preview the most recently edited [[Markdown]] or [[HTML]] file within it, ideal for project-based work.
